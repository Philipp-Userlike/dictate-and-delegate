# Dictate & Delegate 3.1.0

Talk Router is now **Dictate & Delegate**: dictate where you're typing, delegate real work to your agent.

## Changed

- **New name** in the app, setup, notifications and docs. The repository moved to [Philipp258/dictate-and-delegate](https://github.com/Philipp258/dictate-and-delegate); old links redirect.
- **The chief's skill is now `dictate-and-delegate`.** After the update, the app installs it in bb, removes the old `talk-router` skill, and tells your chief of staff once to use the new one.
- **bb sign-in** uses the new address. If you're already signed in, you stay signed in.

Installs over Talk Router 3.0.x; your notes, keys and settings stay.
